
#  Telegram Username Finder Bot

Бот для поиска свободных юзернеймов из 5 или 6 букв с автоматической базой данных.

## 📦 Возможности

- 🔍 Поиск свободных ников длиной 5 или 6 букв
- 🎯 Генерация только читаемых комбинаций (чередование гласных/согласных)
- 🚫 Фильтрация очевидных комбинаций (словарные слова, повторы, клавиатурные ряды, имена)
- 💾 База данных SQLite — сохраняет все проверенные ники
- ⚡ Умный поиск — пропускает уже проверенные ники, ускоряет работу
- 📊 Статистика по проверенным и свободным никам
- ⏱ Защита от блокировки (задержка между запросами)
- 🚀 Готов к деплою на Railway
- 🎛 Удобное управление через кнопки в Telegram

## 🗄 Как работает база данных

1. При первой проверке ник сохраняется в БД как taken или free
2. При следующих поисках бот пропускает уже проверенные ники
3. Это экономит время и ресурсы Telegram API
4. База данных хранится в файле usernames.db (автоматически создаётся)

### Структура БД

- taken_usernames — занятые ники
- free_usernames — свободные ники
- Индексы по длине для быстрого поиска

## 📥 Установка

1. Клонируй репозиторий:
git clone https://github.com/qu31er/Username-FinderBot.git
cd telegram-username-finder

2. Создай виртуальное окружение:
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

3. Установи зависимости:
pip install -r requirements.txt

4. Создай файл .env из .env.example:
cp .env.EXAMPLE .env

5. Отредактируй .env, вставь свои данные:
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
API_ID=1234567
API_HASH=abcdef1234567890abcdef1234567890
PHONE_NUMBER=+71234567890
CHECK_DELAY=2
MAX_RESULTS=10
BATCH_SIZE=100

6. Запусти:
python bot.py

## 🚀 Деплой на Railway

1. Залей код на GitHub (без .env!)
2. На Railway.app создай новый проект
3. Выбери "Deploy from GitHub repo"
4. Добавь переменные окружения в Railway:
   - BOT_TOKEN
   - API_ID
   - API_HASH
   - PHONE_NUMBER
   - CHECK_DELAY (опционально)
   - MAX_RESULTS (опционально)
   - BATCH_SIZE (опционально)
5. Деплой автоматически запустится
6. Важно: При первом запуске бот запросит код подтверждения Telegram в логах Railway. Зайди в логи и введи код.

## 🔧 Переменные окружения

| Переменная | Описание | Обязательно |
|------------|----------|-------------|
| BOT_TOKEN | Токен бота от @BotFather | Да |
| API_ID | API ID с my.telegram.org | Да |
| API_HASH | API Hash с my.telegram.org | Да |
| PHONE_NUMBER | Номер телефона аккаунта | Да |
| CHECK_DELAY | Задержка между проверками (сек) | Нет (по умолчанию 2) |
| MAX_RESULTS | Максимум результатов за раз | Нет (по умолчанию 10) |
| BATCH_SIZE | Размер пачки генерации | Нет (по умолчанию 100) |

## 📝 Как получить API данные

1. Бот токен: напиши @BotFather в Telegram, создай бота и получи токен
2. API ID и Hash: зайди на my.telegram.org, создай приложение

## ⚠️ Важно

- Бот использует твой личный аккаунт Telegram для проверки
- Не злоупотребляй, чтобы не получить блокировку
- Рекомендуемая задержка: 2-3 секунды между запросами
- База данных растёт с каждым поиском, что ускоряет следующие проверки
- Не выкладывай .env файл в публичный доступ!
